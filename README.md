# 宁姆韦德的雨 · nightreign-rain

打《艾尔登法环：黑夜君临》时，**队友全倒地（最后一格）的那一刻自动放你自己选的歌**，
有人被救起来就停。一个 Windows 桌面小工具，抓游戏窗口的左上角 HUD 来判断，
不读游戏内存、不改游戏文件、不联网。

![为什么做这个](assets/cover.jpg)

夜里三个人同时挂在最后一格上，那是整局最安静的一刻。这个工具就是给那一刻配一首歌。

## 它怎么判断

- **只认 HUD 上的东西**。队友的计量表、血条、头像框，这些是 HUD 专属信号；画面里
  出现三个红条不算数。所以队友站在瀑布前面、或者地上有一片血，都不会被当成倒地。
- **位置不用你标定**。程序按"画面实际渲染出来的那块区域"算出队友面板在哪——量出信箱黑边，
  再按画面宽度定位。你把游戏从 2560×1600 无边框改成别的分辨率、或者改了游戏内的
  「界面尺寸」，它会自己跟上；每种分辨率的位置各记各的。
- **不确定就不算**。数队友行要连续若干帧成立；人数要涨得比当前值多、且几帧里多次看到才认；
  读不到表不等于队友站起来。反过来，**停歌**要求"站立的证据"在采集时钟上连续站得住
  （默认 0.8 秒、至少 12 个不同画面、窗口内八成以上证据都站着、最近 0.5 秒没看到倒地）——
  所以卡住的画面、闪一下、隔几分钟的碎片都攒不成一次"被救起"。
  这条规则的依据是：**误停比晚停严重**。
- **过场黑条不会骗它**。一段 0.6 秒的过场压暗画面，会被当成"新的信箱黑边"从而把整套坐标搬走；
  程序框现在要连续稳定 1.5 秒才被采纳。

## 装 / 跑

下载页在 **Releases**，解压即用（单文件 exe，约 56 MB）。首次运行会在 exe 旁边建
`music\` 和 `config.json`。

1. 游戏用**无边框窗口**或窗口化（独占全屏抓不到画面）。
2. 把你的歌丢进 `music\`（mp3 / ogg / flac / wav / m4a / aac / opus / wma，子文件夹也找），
   或者在程序里点「添加音乐…」。
3. 「游戏窗口」下拉里选中游戏 → 「连接」→「开始监听」。
4. 想确认它看到的东西，勾上「显示游戏内悬浮窗」：左上角会浮一个只读队友格数的小窗。
5. 排查为什么没放/为什么停了，勾「记录诊断」，会在 exe 旁写 `diagnostics\<时间戳>\`：
   一行行 `events.jsonl` + 事件前后约 10 秒的 HUD 小图，能离线复现整局。

仓库里**不含任何音频**；Release 里那个 exe 内嵌了作者自己用的两首歌，你换成自己的就行。

## 从源码跑

```
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

测试（约 440 条，纯离屏，不需要游戏在跑）：

```
.venv\Scripts\pip install opencv-python          # 只有等价性测试和生成图需要
.venv\Scripts\python.exe fixtures\make_synthetic.py
QT_QPA_PLATFORM=offscreen .venv\Scripts\python.exe -m pytest -q
```

`fixtures/` 里只随仓库走一张底图，合成用例由 `make_synthetic.py` 生成；
其余真实游戏截图不在仓库里（见 `fixtures/README.md`），需要它们的测试会自动跳过而不是报错。

打包：

```
.venv\Scripts\pyinstaller 宁姆韦德的雨.spec
```

## 界面

| 页 | 干什么 |
| --- | --- |
| 音乐 | 选文件夹、添加音乐、调播放顺序（随机 / 按列表顺序）、音量 |
| 规则与高级 | 触发格数、连续成立帧数、停歌判据、检测帧率、悬浮窗、诊断、恢复默认 |

「恢复默认」只改这一页看得见的字段，曲库、播放顺序、音量和标定位置都不动。

## 已知边界

- 独占全屏抓不到画面（会明确提示）。
- 非等比拉伸画面（把 16:9 硬塞进 16:10）会真的改掉行距，那种救不回来。
- 游戏内「界面尺寸」调到很偏的值时，头像峰的定位偏差会和读数容差撞在一起，
  5 像素上下的位置差可能既不报错也不回头——这类阈值的余量已经用尽，
  代码里每个常数的来源都写在它旁边的注释里。
